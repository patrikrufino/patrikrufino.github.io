# Portfolio Pessoal - Patrik Rufino

Website pessoal e portfolio profissional de **Patrik Rufino**, Desenvolvedor de Software (Java, Spring Boot & React) e graduando em Ciência da Computação.

🌐 **Acesse o site ao vivo:** [https://patrikrufino.github.io](https://patrikrufino.github.io)

## 🛠️ Tecnologias Utilizadas

- **HTML5 Semântico** (SEO, Open Graph, Acessibilidade ARIA)
- **CSS3 / Vanilla CSS** (Design System com CSS Variables, Flexbox, Grid, Glassmorphism e Dark Mode)
- **JavaScript (ES6+)** (Interatividade, Menu Responsivo, Filtro de Projetos)
- **Google Fonts** (Plus Jakarta Sans, Inter, JetBrains Mono)
